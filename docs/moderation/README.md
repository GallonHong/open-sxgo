# 审核与复核演练

1. 只接受虚构演示资料，或在未来正式开关开放后接受已授权公开来源。P0 不接合同、工资条、员工材料及其他内部附件，也不转到邮件/网盘暗中收集。
2. 工单分流：主体全名、城市、岗位/场所、用工类型和工时制度。未明确范围不扩展到整个公司、集团或加盟店。
3. 核对原始来源、转载家族、发布与核对日期、公开制度/实践区别。未知保留为空；官网控制不等于经营主体核验。
4. 初审填写公开候选，不能复制投稿原文、回执、内部工单编号、精确员工人数或私密线索。遇利益冲突退出；权限不能自行扩大。
5. 第二位独立人员复核主体、范围、来源、资格时效、隐私与文案。同一 `person_id` 不得复核自己提出的候选。
6. 通过后只能成为待发布候选。正式发布另需审核业务签名和 Targets 发布阈值；后台无生产私钥。
7. 变化、隐私、冒用、错误链接、申诉分开处理。紧急暂停只减少推荐，恢复仍需独立审核。申诉至少一个未参与原决定的人；没有独立人员时保持暂停。

当前后台具有候选编辑、复核和导出；尚未提供完整网站挑战/店铺核验、签名采集、广告档案、治理授权管理界面。不要借用高级 JSON 导入绕过这些生产前置条件。

复核目标（PRD 模板）：两工作日分流、资料齐备后七工作日初审或说明延期。后台实际队列应作为排班依据，不能由目标期限自动宣称已经按期核验。
