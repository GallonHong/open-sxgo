# 隐私、日志与留存

公开数据 PUB、运维 OPS、投稿 SUB、未来附件 EVD、密钥 KEY、推广档案 AD 必须分开。公开站/镜像只取签名 PUB。私密投稿不发给第三方 AI、不加载外部统计。回执仅在首次成功响应和用户恢复文件中出现，后续请求使用 `X-WFD-Receipt`，不放 URL。

数据库只存回执摘要。幂等重试不重复建工单，也不返回回执明文；若首次响应丢失、用户未取得回执，目前不能找回，这是需进一步优化的提交恢复边界。不能声称匿名且无限可恢复。

版本化默认策略在 `packages/domain/src/retention.ts`。关闭的 P0 投稿 90 天后清空正文、对话和认证摘要；公开批准记录另行保存；受合法保全且未到期的记录不自动清理。演示后台尚无保全审批管理界面。广告档案没有上线，不套用投稿的短期清理任务；生产前按适用义务独立配置。

服务代码不记录请求正文或凭证。Cloudflare/CDN/反向代理/设备可能产生日志，哈希 IP 不等于匿名。真实供应商配置、跨境路径和日志留存须上线前审查。审计理由不能粘贴员工原文、令牌或密钥。

合理删除请求经分类工单处理；主库清理不能代表已清除供应商备份、访问日志、审核员截图或第三方公开镜像。部署侧必须进行可核对的备份生命周期和临时副本删除演练，不承诺全球抹除。
