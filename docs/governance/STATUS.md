## 本轮集成修正

- 暂停新投稿不会阻断成员工作、撤回与隐私请求；暂停边界已在 SQLite/D1 验证。
- 每次高权限请求读取当前账号、会话、授权与对象范围，不信任调用方提交的 actor、评估者或执行结果。
- 成员贡献、资格和申诉响应只返回所需工作状态字段，原始引用、存储摘要与内部关联不会随结果返回；私密引用诱饵已覆盖创建和列表接口。
- 申诉必须由两位独立人员分别提交决定，不能提交评估者名单冒充两次判断。
- 案件可以先建初稿、处理来源并绑定预览，再分配双审；无有效预览不能批准。
- 已验证元数据单独持久化；后续下载失败后仍拒绝回滚。完整旧快照继续用于历史浏览。
- 跨版本更新验证逐个历史摘要。发布向每个副本复制并读回连续根与历史清单，缺失历史时不切换发现入口。客户端单次最多追赶 64 版；更长中断仍需受控恢复流程。
- 清理任务删除过期预览并尊重有期限的保全；角色/资格到期不自动恢复。主库清理不代表供应商日志、隔离处理器和备份已清理。
- 本机旧数据库曾记录开发中的早期迁移摘要。已先建立私密备份，仅重建确认无业务记录的新表及可重建的旧身份导入表，逐表比较保留的 17 张旧表内容摘要；旧投稿和账号保留。迁移摘要检查继续启用。

## 复查命令

本轮已执行记录：整仓 23 个测试文件、168 项测试通过；三浏览器 21 项流程通过；TypeScript 检查、三个前端构建和 Worker dry-run 通过。真实 Chromium 虚拟认证器注册与再次认证通过；离线治理签名 10 项测试通过，包含 SQLite/D1 执行器和两次 CLI 签署。结果见对应演练文档。本记录不是生产上线批准。

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
pnpm worker:check
```

容器版清理使用 `WFD_DB_PATH=<私密数据库路径> pnpm maintenance`，由部署方的定时任务调用；Workers 已接入每日 scheduled handler。

本地环境：macOS arm64、Node.js 24、SQLite 与 Miniflare D1。Miniflare 测试日期使用其已支持的 2026-07-30；Workers 配置日期为 2026-09-12。打包通过不能代替真实云端执行测试。
