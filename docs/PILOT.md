# 受邀小规模试运行 · 准备记录

本轮规模：5–10 人，包含两名不同人员担任审核员；另指定测试负责人。当前状态为准备中，尚未开放招募或通过正式上线门槛。邮箱、人员映射、凭据只保存在私密配置，不能提交到本仓库。

## 开始前必须完成

- [ ] 测试负责人、第二名独立审核员及其余测试者名单确认。已收到一名拟任审核员的邮箱，尚未完成人员核实。
- [ ] 两名审核员分别完成人员登记、账号绑定、限范围限时授权、密码/TOTP 和 WebAuthn 注册；负责人核对两者确为不同人员并记录利益冲突。
- [ ] Sites 仅授权指定测试者访问，保留所有者；不改为公开访问。Sites 访问许可与应用内审核权限分别验证。
- [ ] 线上账号开通路径和审核工作台完成实际演练。`pnpm auth:invite` 只用于本地演示，不能开通线上 D1 账号，不能直接赋予生产权限。
- [ ] 在数据与验证页核对发布期限，在剩余有效期至少 24 小时的条件下安排 24 小时测试；没有排定日期前不声称已经启动。
- [ ] 负责人准备私密数据库备份、停收投稿操作、日志查看与问题记录；确认数据保留和删除责任人。

## 执行顺序与验收

| 编号 | 谁执行 | 操作 | 预期与记录 |
| --- | --- | --- | --- |
| PILOT-01 | 未获邀测试账号 | 访问首页、投稿、审核入口 | Sites 访问被拒绝，记录时间与结果 |
| PILOT-02 | 浏览者 | 阅读苹果详情、逐个打开来源、筛选周末双休 | 能区分报告声明与岗位实际执行；苹果不命中已核实双休，不进入推荐名单 |
| PILOT-03 | 投稿者 | 提交一条带公开来源的范围明确资料 | 获得私密回执；不在 URL 中传递；不得使用内部材料 |
| PILOT-04 | 投稿者 | 刷新、查询、补充、撤回、无效回执查询 | 结果持久化；无效回执不能读他人资料；记录回执是否泄漏，不记录回执本身 |
| PILOT-05 | 审核准备人员 | 净化公开候选、绑定来源与范围、分配审核 | 候选不包含身份材料；两人看到同一版本，记录案件编号与版本 |
| PILOT-06 | 两名审核员 | 分别认证并独立审核 | 自审、冲突与越权被拒；不能用一人两账号满足要求；修改候选后旧决定失效 |
| PILOT-07 | 审核员 | 批准候选后查看公开目录 | 目录不自动更新；生产发布和推广仍关闭 |
| PILOT-08 | 浏览者 | 缓存后离线打开；再恢复网络 | 已验证旧资料可历史浏览；到期状态明确；新设备不得绕过签名与过期验证 |
| PILOT-09 | 负责人 | 查看积压、纠错、停止投稿、备份恢复 | 指定人员可以响应；撤回与隐私请求不因停收新稿而关闭；恢复在隔离环境验证 |

每项记录测试版本、环境、日期、实际结果、问题编号和复测结果。自动测试只作为入场检查，不能代签人工验收。

## 停止条件

遇到回执或个人信息泄漏、越权访问、同人双审通过、候选版本错配、签名错误或无效资料被展示为当前推荐时，立即停止相关测试。负责人停收新投稿并保留受限事件记录；修复与复测前不扩大访问范围。不把关闭整个站点当成撤回或隐私请求的长期替代路径。

## 退出与下一步

所有适用 PILOT 项目由真实人员完成、阻断问题清零并复测后，才能决定下一轮规模；这不替代 PRD 的 GATE-01～GATE-10。GATE-06 未满足时仅允许清楚标记的封闭演示。来源摘要不是独立劳动审核，苹果仍为待核实参考记录。
