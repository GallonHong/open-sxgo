# open sxgo 网站交付边界

公开网页使用一个真实主体：苹果电子产品商贸（北京）有限公司。依据 Apple 中国大陆销售政策列示的名称，登记信息仍待复核。该来源不支持任何劳动条件结论，所有劳动条件保持未知。参考记录与符合收录条件的推荐记录分别展示，未改变后台资格规则。测试用合成数据只用于自动测试，不进入公开发布包。

来源：https://www.apple.com.cn/shop/open/salespolicies （查阅 2026-09-12）。仅整理事实和来源链接；Apple 内容、名称和商标不因本项目 MIT 代码许可而被重新授权。项目不隶属 Apple。

Sites 仅托管只读公共前台，不发布私密数据库、账号、回执或测试管理员。投稿未开放时，线上资料整理表只生成用户主动下载的本地草稿，不会提交服务器。贡献代码可通过 GitHub 进行。受控投稿、成员和审核应用保留独立部署能力；需要完成部署与独立治理后才能配置其公开入口。正式签名发布仍关闭，当前元数据使用测试信任根，到期按历史资料展示。

删除消费导航、发现页及品牌消费页；不再输出示例产品。完善成员贡献回执关联界面，回执只经请求头传输，并要求明确同意，服务端检查当前身份与记录版本。
